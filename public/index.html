Halftone QR Code Generator

Turn any picture into a QR code that still scans: the image shows through the code as a halftone pattern.

This tool runs entirely in your browser. Your images and text are never uploaded. You are responsible for making sure you have the rights to use any image you put in a QR code.

Drop an image onto the page or choose a file. The QR code updates as you change the settings.

About the simulated scan

The page imitates what a phone camera would see: it shrinks the code to about 8 pixels per module, blurs it slightly, and converts it to black and white the way scanner apps do. It then reads every module, including with the reading grid slightly misaligned, and checks whether error correction could fix the mistakes.

It can't simulate lighting, glare, shadows, viewing angle, camera shake, distance, print or screen quality, or differences between scanner apps. A code that passes is likely to work, but it's still an estimate: always test with a real phone, ideally two.
